## Intent

Increase the mechanically proven response and semantic contract coverage of
approved real source surfaces discovered by Phase 25. The implementation must
be driven by a fresh bounded source scan, extend the existing analyzer and
semantic-coverage architecture, and route new proof directly through the
existing Phase 24 candidate authority.

## Required outcome

Deliver a coherent local/source/synthetic vertical slice:

```text
fresh approved source snapshot
  -> deterministic proof-gap census
  -> bounded response/semantic analyzers
  -> exact cross-file proof joins
  -> source graph/lifecycle/currentness/invalidation
  -> existing Phase 24 candidate bridge and portfolio
  -> semantic/replay/dossier/review projections
```

The primary measurable result is a truthful increase in response and semantic
contracts and lifecycle advancement for the current approved source snapshot.
Unsupported or dynamic source must remain visibly excluded; coverage numbers
must never be increased by guessing.

## Authority and safety

- This phase is LOCAL / READ-ONLY SOURCE / SYNTHETIC ONLY.
- Approved Alphaus sibling repositories are read only and may be accessed only
  through the existing confined source boundary.
- No DEV, NEXT, production, browser, product API, authentication-state,
  database, datastore, cloud, infrastructure, deployment, publication,
  messaging, or Alphaus write operation is authorized.
- Source text is ephemeral analyzer input only. No raw source, private value,
  customer-like value, credential, token, cookie, or reconstructible member set
  may enter persisted DTOs, receipts, dossiers, task records, logs, or
  committed fixtures.
- Existing Phase 24 qualification, portfolio selection, replay, dossier, and
  execution-safety rules remain authoritative. Phase 26 cannot grant
  execution authority.
- Every new positive proof requires a valid, ambiguous, and invalid nearby
  regression plus deterministic privacy-safe output.

## Non-goals

- No generic parser framework, dynamic execution, AI semantic authority, or
  runtime inference.
- No second portfolio, selector, replay planner, dossier framework, semantic
  graph, or quality gate.
- No broad scan outside the existing approved source universe and bounded
  synthetic corpus.
- No deployment-equivalence inference, human-owner inference, or product
  correctness claim from source proof alone.
- No repeated external CI retries and no DEV acceptance.

## Acceptance shape

The completed task must include a fresh before/after proof-gap report,
mechanically sound response/semantic extraction improvements, exact join and
currentness coverage, Phase 24 integration, lifecycle/invalidation/cache
tests, adversarial proof-soundness tests, offline source-to-triage synthetic
integration, operator-visible gap metrics, and the repository's current local,
compatibility, clean-checkout, and full-regression certification.
