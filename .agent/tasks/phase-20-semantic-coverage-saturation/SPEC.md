# Phase 20 — Semantic Coverage Saturation and Cross-Surface Differential Detection

Status: FROZEN INTENT

## Objective

Increase Nightwatch's local, deterministic detection yield by discovering a
larger mechanically justified universe of source-backed behavior, admitting
only proven contracts, connecting those contracts to existing semantic and
campaign authorities, and measuring relational, differential, and
metamorphic detection strength.

## Authorization and safety boundary

Authorization class:
`PHASE_20_SEMANTIC_COVERAGE_SATURATION_LOCAL_SOURCE_SYNTHETIC_ONLY`

This phase is LOCAL / SOURCE / SYNTHETIC only. It may inspect approved sibling
source through the existing path-confined read-only boundary, build bounded
synthetic fixtures, evaluate sanitized projections, plan local synthetic
campaigns, replay and minimize safe synthetic cases, and write task/source
fixtures and tests in Nightwatch. It must not contact DEV/NEXT/production,
load authenticated state, query databases/datastores/cloud/infra, mutate
sibling repositories, publish or message findings, persist raw values, add
AI/self-development authority, or infer execution authority from priority.

The permanent owner decision remains
`FROZEN_BY_OWNER / INFRASTRUCTURE_AND_DATA_LAYER_OUT_OF_SCOPE`.
Phase 19 is terminal and is composed, never reopened or mutated.

## Scope

The implementation is additive to Phase 9–19 and includes:

1. a versioned deterministic contract-discovery inventory with explicit
   proof/rejection/currentness states;
2. bounded syntax-aware analyzers for source patterns present in the local
   approved source ecosystem, with unknown syntax rejected;
3. relational semantic contracts and a deterministic source-to-dossier
   contract graph;
4. an equivalence-bound cross-surface differential engine;
5. provenance-backed metamorphic relations;
6. contract-derived synthetic fixtures and bounded mutants;
7. mutation-style synthetic detection measurement with benign/privacy floors;
8. source drift classification and explicit re-derivation requirements;
9. additional privacy-safe semantic projection properties;
10. richer synthetic multi-surface product fixtures;
11. Phase 19-integrated coverage-gap ranking and campaign auto-composition;
12. compact contract-chain/differential/mutation evidence in dossiers and
    safe local operator views;
13. a substantially expanded data-driven adversarial corpus and source-keyed
    bounded caches.

## Non-goals

Real product semantic acceptance, new DEV/NEXT authority, infrastructure or
data-layer work, external publication, raw value retention, heuristic source
meaning, generic parsing without proof, fuzzing, AI evidence authority,
self-development promotion, or replacement of Phase 19 coverage/planning.

## Design constraints

- Source discovery is never semantic authority. Every record carries source
  provenance, analyzer identity, evidence identity, and an explicit proof
  state.
- An unknown analyzer pattern, relational kind, differential kind, or
  metamorphic relation fails closed with a stable reason code.
- Raw source/customer/application values never cross the projection boundary
  or enter findings, fingerprints, graph DTOs, dossiers, fixtures, or task
  records. Only bounded categories, counts, booleans, safe paths, and opaque
  digests are emitted.
- Source identities are exact. A changed source is never silently rebound;
  affected contracts become stale and require fresh derivation.
- Priority remains selection metadata only and can never bypass owner policy,
  currentness, authority, or executor gates.
- All output is deterministic with bounded input sizes and canonical ordering.

## Completion bar

Completion requires executable end-to-end use of the discovery → admission →
graph → projection/oracle → differential/metamorphic → mutation measurement →
Phase 19 coverage/planning → replay/minimization → dossier/operator path,
focused and compatibility regressions, expanded adversarial coverage, zero
benign/privacy/safety regressions, typecheck/hardening/continuity/project
checks, canonical and topology-correct isolated parity, and truthful
external-CI reporting.
