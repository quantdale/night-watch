## Required architecture

### A. Real eligibility and source proof

Add deterministic eligibility states:

`SYNTHETIC_ONLY`, `REAL_SOURCE_NO_RUNTIME_BINDING`,
`REAL_SOURCE_RUNTIME_BINDING_AVAILABLE`, `REAL_SOURCE_RUNTIME_BINDING_STALE`,
`REAL_SOURCE_PROJECTION_UNAVAILABLE`, `REAL_SOURCE_AUTHORITY_BLOCKED`, and
`REAL_SOURCE_DEV_ACCEPTANCE_ELIGIBLE`.

Eligibility requires mechanically proven current source, derivation evidence,
approved read-only target, current runtime adapter, privacy-safe projection,
replay support, no mutation, allowlisted DEV host, and owner authority.

Fresh source discovery must classify `CURRENT_EXACT`,
`SOURCE_CHANGED_SEMANTICS_UNCHANGED`, `REDERIVATION_REQUIRED`,
`CONTRACT_CHANGED`, `CONTRACT_REMOVED`, `SOURCE_UNAVAILABLE`, or
`UNSUPPORTED_NOW`. Expectations never silently rebind to a new SHA.

### B. Frozen manifest and preflight V2

Introduce immutable metadata-only
`nightwatch.dev-semantic-acceptance-manifest.v1`. It contains only safe
product/surface/contract/expectation/source/evidence/projection/differential/
replay/observation/count/preflight identities and explicit exclusions. The
deterministic planner selects at most six genuinely distinct targets; execution
performs no live target discovery.

Add a versioned preflight receipt covering environment/host, production/NEXT
rejection, L0–L5 containment, QUIC/WebRTC/trace/screenshot/raw persistence
settings, mutation registry, external regular storage-state safety, auth
readability, source/expectation/adapter currentness, owner policy, no DB/infra,
and clean Git state. Any failed gate stops before DEV contact.

### C. Runtime privacy and semantic acceptance

Add a runtime privacy firewall between authenticated observation and projection.
Only bounded categories, counts, relation truth classes, differential outcomes,
and deterministic opaque evidence digests may cross it. Raw strings/numbers,
identifiers, emails, account/MSP names, billing values, tokens, cookies,
storage state, raw bodies, DOM fragments, and enum/member values are rejected.

Integrate real-source collection-wide and finite-membership projections where
eligible, preserving partial coverage as non-PASS. Classify every candidate for
real differential eligibility without inferring a second surface from names.
FIRST + one fresh-context REPLAY are contract/source/evidence bound and use no
third run. Real minimization is safe-plan reduction only; otherwise emit
`REAL_MINIMIZATION_NOT_AUTHORIZED`.

### D. Calibration, dossier, operator, and dry run

Record safe per-target and aggregate calibration metrics. Compare synthetic to
real behavior only at semantic-category level using fixed categories; zero
findings never proves correctness. Real HIGH confidence requires current source,
resolved expectation, decisive real observation, fresh replay, stable identity,
complete privacy receipt, and no precondition divergence.

Add sanitized real-acceptance dossier mode and local dry-run/manifest/preflight/
results/explain surfaces following the existing CLI architecture. The exact
frozen manifest must pass a synthetic no-contact dry run before DEV.
