interprocedural PHP response-flow resolver can safely eliminate recurring
helper/resource/DTO exclusions, then implement only the mechanically proven
subset and harden the surrounding source-intelligence stack.

## Safety Constraints

All sibling reads remain behind the confined read-only source boundary. Source
text is ephemeral; raw/private values never persist. Unknown, dynamic,
ambiguous, stale, incomplete, cyclic, or unsupported behavior fails closed.
Response proof never establishes mutation/read-only safety.

## Architecture / Approach

Reuse Phase 26 direct-response proof and the existing semantic/graph/cache/
Phase 24 seams. Add only a small exact declaration index/resolution layer if
the census demonstrates a repeatedly useful admissible family; bind every
dependency into proof identity and use an explicit depth/cycle budget. If the
census does not support sound joins, harden currentness/privacy/determinism
instead.
