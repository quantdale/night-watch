# Phase 19 — Autonomous Bug-Yield Expansion and Integrated Campaign Intelligence

Status: FROZEN INTENT

## Objective

Increase Nightwatch’s local, deterministic bug yield by making source/change
intelligence, semantic coverage, campaign selection, execution evidence,
replay, minimization, nondeterminism analysis, confidence, clustering, and
owner-ready triage one mechanically explicit pipeline. The implementation is
additive to proven Phase 9–18 machinery and remains LOCAL / SOURCE / SYNTHETIC.

## Authorization and safety boundary

Authorization class:
`PHASE_19_AUTONOMOUS_BUG_YIELD_LOCAL_SOURCE_SYNTHETIC_ONLY`

The owner freeze remains:
`FROZEN_BY_OWNER / INFRASTRUCTURE_AND_DATA_LAYER_OUT_OF_SCOPE`.

This phase may inspect local source through existing read-only boundaries and
may create synthetic fixtures, sanitized evidence, deterministic plans,
replays, minimization traces, reports, and private local operator output. It
must not contact DEV/NEXT/production, use authenticated state, query or infer
cloud/datastore/infrastructure state, modify sibling repositories, publish or
message findings, persist raw values, or treat AI output as evidence authority.
Priority and operator commands never grant environment authority.

## Scope

The phase implements a cohesive set of additive capabilities:

1. versioned deterministic campaign planning and explainable priority;
2. behavior-level change impact flowing into plan selection;
3. multi-stage semantic coverage accounting;
4. sanitized campaign yield analytics and coverage deltas;
5. replay fidelity V4 outcome/divergence taxonomy;
6. reduction search with explicit minimality proof strength;
7. bounded nondeterminism/flakiness classification;
8. safe semantic/protocol clustering and duplicate suppression;
9. confidence V2 with blocking/degradation reasons;
10. stable owner dossier sections and precise next actions;
11. genuinely extensible product/surface adapters with synthetic genericity
    fixtures;
12. data-driven adversarial corpus expansion, safe local operator commands,
    diagnostics, and correctness-preserving bounded caching.

Existing Phase 9–18 semantic, source-provenance, replay, triage, safety, and
compatibility contracts remain readable and behaviorally compatible unless a
new version is explicitly named.

## Non-goals

- canonical self-development or promotion;
- real DEV/NEXT acceptance;
- infrastructure/data-layer work;
- external analytics, telemetry, issue filing, or publication;
- raw customer/application evidence in source, artifacts, findings, or task
  records;
- heuristic or AI-derived evidence authority;
- deleting truthful historical phase records.

## Completion bar

Completion requires executable end-to-end use of the new planning → impact →
coverage → execution evidence → replay/minimization → confidence/clustering →
dossier/yield path, focused regression coverage for the requested adversarial
classes, zero benign-control/privacy/safety regressions, green typecheck and
hardening/continuity/project checks, canonical and topology-correct isolated
regression with exact enumeration/skip parity, and truthful external-CI status.
